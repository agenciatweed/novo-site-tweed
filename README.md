# Novo site da Agência Tweed

Site institucional estático. A versão aprovada está em `site/parallax/`.

- Domínio canônico: https://www.agenciatweed.com.br/
- Repositório: https://github.com/agenciatweed/novo-site-tweed
- Orientações de trabalho: `AGENTS.md`.
- Sistema visual: `DESIGN.md`.
- Contexto da expansão: `CONTEXT-SEO-GEO.md`.
- Limites e procedimento de publicação: `docs/PUBLICACAO.md`.

Não há build obrigatório. HTML, CSS e JavaScript estão em `site/parallax/index.html`, com recursos em `site/parallax/assets/`.

## Escopo do Git

O `.gitignore` permite apenas o site final e a documentação técnica selecionada. Documentos comerciais, contexto pessoal, carteira de clientes, versões descartadas e cópias locais de produção ficam fora do versionamento. Novos arquivos na raiz precisam de inclusão explícita na lista permitida.

Não publicar a raiz deste repositório na hospedagem. A documentação e os arquivos internos não fazem parte do site.

Não fazer commit ou push sem solicitação explícita, conforme `AGENTS.md`.
